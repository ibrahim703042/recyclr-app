# Product Overview

**Recyclr** is an Android mobile application focused on recycling and waste management. The app provides:

- **User Authentication**: Email/password authentication with Firebase, including sign-up, sign-in, password reset, and email verification
- **Location Services**: Integration with Google Maps for location-based features (likely for finding recycling centers or waste collection points)
- **Dashboard Interface**: Main user interface with bottom navigation for core features

The app follows a clean, modern design using Jetpack Compose for UI and targets environmental sustainability through improved recycling accessibility.
